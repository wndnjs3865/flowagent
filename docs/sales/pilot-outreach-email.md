## 변형

- **Follow-up (5영업일 무응답)** — subject `[Re] FlowAgent Pilot 미팅 신청 드립니다`, body는 2문단으로 압축: "지난 메일 회신 확인이 어려우셔서 한 번 더 짧게 드립니다. 일정 후보 한 줄만 회신 주셔도 나머지는 저희가 조율하겠습니다."
- **Warm intro (지인·고객 소개)** — body 1번째 문단 앞에 `{{소개자명}}님 통해 연락드립니다.` 한 줄 추가. subject에 `({{소개자명}} 소개)` 꼬리표.
- **1차 데모 완료 → 설치 미팅 제안** — subject `FlowAgent 설치 미팅 — {{회사명}} 1주차 진행 일정 조율`, body는 데모에서 합의된 사례명·Pilot 4주 일정 reaffirm 위주로 교체. README "After demo — leave-behind" 4번 항목과 짝이 되는 메일.

## 보내는 사람을 위한 메모

- **개인 메일 톤 유지** — "운영하는 {{발신자명}}입니다"로 시작, "회사 소개서" 톤 금지. SMB 담당자는 1인 창업자/소수팀과의 직거래를 더 빠르게 처리한다는 가설.
- **요청은 한 번에 하나** — 미팅 일정 + 샘플 1건. 두 가지를 동시 요청하되 샘플은 "가능하시다면" 조건부로 두어 회신 장벽을 낮춤.
- **링크 vs 첨부** — 1-pager는 PDF 첨부만 사용 (GitHub raw 링크는 사내 보안망에서 차단되는 경우 많음). README 링크는 미팅 확정 후 calendar 초대장에 동봉.
