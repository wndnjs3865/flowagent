# FlowAgent — Pilot 1-pager

> **한 번 설정하면, 업무가 알아서 흐른다.**
> 한국 중소기업 실무자의 매일 반복되는 사무 업무 스트레스를 줄이는 로컬 워크플로우 도우미.

---

## 1. 우리가 해결하는 문제

10~200인 SMB 사무·운영팀에게 매일 발생하는 잡일은 의외로 많다.

- 주간 보고서를 매주 비슷한 양식으로 다시 쓰기
- 회의록을 다시 읽으며 액션 아이템을 추리기
- 월말마다 매출 CSV를 들여다보며 1-pager 만들기
- 고객 문의에 비슷한 톤으로 매일 답변하기
- 결재함에 줄 선 요청을 하나씩 읽고 통과/반려 판단하기

"중요하지만 반복되는" 일이라 자동화 가치가 크지만 — n8n/Zapier는 코딩 장벽, 일반 SaaS는 회사 데이터를 외부에 올려야 함, ChatGPT는 매번 같은 프롬프트를 다시 붙여넣어야 함.

## 2. 우리의 해결책

**FlowAgent**는 노트북 한 대에서 돌아가는 워크플로우 도우미다.

- **로컬 우선** — 회사 데이터가 노트북을 벗어나지 않음. Anthropic API 호출 시에만 LLM에 텍스트 전송, 다른 SaaS에 절대 저장 안 됨.
- **No-code** — 사무직이 한 번 본 YAML 1개만 있으면 한국어 출력으로 결과가 나옴.
- **5분 시작** — clone → `pnpm install` → `.env` → `pnpm dev` → 브라우저에서 Run.
- **모든 실행 자동 기록** — `runs/<runId>.jsonl`로 감사·재현·월간 효과 리포트.

### 비교 한 줄

| | n8n / Zapier | ChatGPT 단발 사용 | 사내 RPA 외주 | **FlowAgent** |
|---|---|---|---|---|
| 데이터 위치 | SaaS 클라우드 | OpenAI 서버 | 사내 서버 | 노트북 로컬 |
| 시작 시간 | 1~2일 학습 | 즉시(매번 프롬프트 재입력) | 수 주~수 개월 | 5분 |
| 비개발자 운영 | 어려움 | 가능(단발) | 불가 | 가능 |
| 결과 재현·감사 | 부분 | 없음 | 있음 | 자동 JSONL |

## 3. 즉시 제공되는 자산 (5종)

| Workflow | 페르소나 | 줄여주는 반복 업무 스트레스 |
|---|---|---|
| 주간 보고서 작성기 | 팀 리드 / 매니저 | 매주 같은 보고서 처음부터 다시 쓰기 |
| 회의록 → 액션 추출 | 운영 / PM | 회의 후 회의록 다시 읽으며 액션 정리 |
| 매출 데이터 요약 | 영업관리 / 대표 보고 | 월말 이상치 찾고 경영진 1-pager 만들기 |
| 고객 문의 분류 + 답변 초안 | CS팀 | 같은 톤 답변 쓰고 우선순위 매기기 |
| 결재함 자동 분류 + 오늘의 brief | 총무 / 사무관리 | 결재함 줄선 요청 하나씩 판단하기 |

위 5종은 모두 한국어 fixture + 한국어 출력으로 즉시 시연 가능. Pilot 미팅 자리에서 귀사 데이터 1건으로 함께 1개 더 만들어 드림.

### 실제 출력 미리보기 — `meeting-actions` Slack 포맷 단계

회의록 1건(약 1,200자)을 입력했을 때 마지막 단계에서 나오는 한국어 출력 예시. Slack에 그대로 붙여넣을 수 있다.

```
이번 주 액션 아이템 정리해드릴게요 👇

*이팀장*
• [5/16] 단골 고객 사은품 제공 방안 초안 작성
• [5/18] 쿠팡 광고비 재편성 안 회의 전 보고

*박매니저*
• [5/15] 마케팅 주니어 채용공고 초안 작성
• [5/17] 4월 매출 1-pager 대표님 보고

*김CS*
• [5/14] 5월 첫째 주 문의 카테고리별 답변 가이드 정리
```

전체 실행 시간 약 20초. 같은 회의록을 사람이 정리하면 평균 15~20분. 출력은 `runs/<runId>.jsonl`에 자동 보존.

|---|---|---|---|
| 주간 보고서 작성기 | 30분 | 주 1회 | 2.0h |

## 5. Pilot 진행 방식 (총 4주, **3사 한정**)

Solo 운영 체제라 동시에 깊이 들어갈 수 있는 회사는 3곳입니다. 한 회사에 4주간 같이 워크플로우를 만들고 실측 ROI를 회고하는 게 우선이기 때문에, 4번째 회사부터는 대기 리스트로 받습니다.

| 주차 | 활동 | 소요 |
|---|---|---|
| 0주차 | 인트로 미팅(30분) + 5분 라이브 시연 + 귀사 케이스 1건 정의 | 60분 |
| 1주차 | 설치(5분) + 귀사 케이스 워크플로우 함께 작성 + 사내 1인 단독 운영 시작 | 90분 |
| 2주차 | 1주차 운영 결과 회고(30분, 화상) + 워크플로우 1개 추가 또는 튜닝 | 60분 |
| 3주차 | 4주 누적 `runs/*.jsonl` 분석 → 시간 절감 실측치 산출 → 정식 도입 의사결정 회고 | 60분 |

**Pilot 동안 라이센스 비용은 0원**. Anthropic API 종량(약 ₩5K~₩30K/월 예상)만 귀사 부담. 정식 가격은 Pilot 결과를 함께 본 뒤 별도 협의.

## 6. FAQ

**Q. 회사 데이터가 외부로 나가나요?**
A. 워크플로우 실행 시 Anthropic API에 텍스트가 전송되는 것 외에는 어떤 외부 SaaS에도 저장되지 않습니다. 노트북 안의 `workflows/` 폴더에서 모든 게 시작·종료됩니다. 정책상 더 강한 차단이 필요하면 사내 LLM(예: vLLM) 연동 검토 가능.

**Q. 비개발자도 워크플로우를 만들 수 있나요?**
A. YAML 파일 한 개만 만들면 됩니다. 첫 미팅에서 귀사 케이스 1건을 함께 만들어 드립니다. 그 후엔 같은 패턴을 복사해 변형만 하면 됩니다.

**Q. 설치가 어렵지 않나요?**
A. `git clone` → `pnpm install` → `.env`에 API 키 한 줄 → `pnpm dev`. README의 Demo path 7단계대로 따라하면 5분 안에 첫 결과가 나옵니다.

**Q. 결과가 잘못 나오면요?**
A. 모든 실행 이력이 `runs/<runId>.jsonl`에 자동 저장됩니다. 어떤 입력에 어떤 출력이 나왔는지 100% 재현 가능. 프롬프트를 한 줄만 고치면 다음 실행부터 반영됩니다.

**Q. 우리 회사 케이스로도 되나요?**
A. 됩니다. fixture 자리에 귀사 실제 데이터 샘플(회의록·매출·문의·결재 메일 등)을 넣고 프롬프트를 한국어 SMB 톤으로 다듬으면 됩니다. 미팅 자리에서 1건 같이 만들어 드립니다.

**Q. 4주 후에 도입 안 해도 되나요?**
A. 됩니다. 코드는 그대로 노트북에 남고 라이센스 의무도 없습니다. 운영 회고 자료(시간 절감 실측치)는 귀사 자산으로 전달합니다.
